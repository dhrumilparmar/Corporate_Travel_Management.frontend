# Corporate Travel Management System - Frontend

Angular frontend for the Corporate Travel Management System. This application provides role-based dashboards for employees, managers, finance users, and admins to manage travel requests, approvals, expenses, and policy-based workflows.

## Backend Repository

Spring Boot backend is available here:
https://github.com/dhrumilparmar/Corporate_Travel_Management.git

## Tech Stack

* Angular 18
* TypeScript
* HTML
* CSS
* Angular Routing
* Angular Services
* HTTP Client
* Route Guards
* HTTP Interceptor
* JWT Authentication

## Features

* Login with JWT authentication
* Role-based dashboards
* Sidebar navigation
* Employee travel request creation
* Request history and status tracking
* Manager approval/rejection workflow
* Finance approval workflow
* Expense management UI
* Profile and budget details pages
* REST API integration with Spring Boot backend

## Angular Concepts Used

* Components
* Services
* Routing
* Route Guards
* Dependency Injection
* HTTP Client
* HTTP Interceptor
* Forms
* Data Binding
* Event Binding
* Conditional Rendering
* localStorage-based JWT handling

## Run Frontend

```bash
npm install
ng serve
```

Frontend runs on:

```text
http://localhost:4200
```

## Run Backend

Clone and run the backend:

```bash
git clone https://github.com/dhrumilparmar/Corporate_Travel_Management.git
cd Corporate_Travel_Management
mvn spring-boot:run
```

Backend runs on:

```text
http://localhost:8080
```
